# Covoiturafpa

Dépôt contenant la base de données PostgreSQL du projet Covoiturafpa.

commande pour lancer la base de donnée:
docker compose up
Puis se connecter sur localhost:5050 sur navigateur


-addToPath.bat sert a ajouter la commande .\dockerdu dans les variables d'environement
-dockerdu.bat contient les commandes pour down et up direct le container docker (commande a faire a la source)
